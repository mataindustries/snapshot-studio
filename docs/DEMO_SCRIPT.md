# Snapshot Studio: 3-Minute Demo Script

## Before recording

1. Run `npm ci` and `npm run dev`.
2. Open the app at desktop width with browser zoom at 100%.
3. For the cleanest recording, use fresh site storage. Otherwise select **Reset Starter Workspace**, then reload and return to the top.

## 0:00–0:15 — The promise

Show the first screen.

> Snapshot Studio turns one local-business lead into a reviewed growth plan, client Snapshot, implementation roadmap, proposal, and outreach package. The operator stays in control from start to finish.

Select **Load Starter Workspace**.

If the guide was dismissed in this browser, select **Restart tour** immediately afterward.

## 0:15–0:35 — Lead

The **Lead** tour step highlights the complete fictional Harbor & Pine Heating Co. record.

> We start with the business essentials and one valid contact route. Loading this demo reuses the same stable records, so it never fills the queue with duplicates.

Select **Next**.

## 0:35–1:00 — Review

The tour moves to the Operator Intake Workspace.

> Research is entered manually—Snapshot Studio does not crawl the web. Deterministic analysis organizes only the supplied material, and the operator reviews every score, claim, strength, and opportunity before applying it.

Point out the saved, reviewed intake and evidence handoff. Select **Next**.

## 1:00–1:35 — Snapshot

The tour highlights the client report.

> The Snapshot reads like an executive consulting brief: a concise business summary, five-category score strip, clear highest-leverage improvement, and evidence-aware recommendations. Visuals use existing scores and remain readable in print, grayscale, and copied text.

Briefly scroll through the executive summary and Opportunity / Effort Matrix. Select **Next**.

## 1:35–2:00 — Roadmap

The tour highlights Action Control Center.

> The same canonical actions power the matrix, momentum timeline, 48-hour sprint, first-month roadmap, and live progress. One demo action is complete, one is in progress, and the rest are not started.

Point out the current next milestone and dependency-aware statuses. Select **Next**.

## 2:00–2:25 — Proposal

The ready proposal opens in Proposal Workspace.

> Proposal scope is not retyped. It reuses the approved Snapshot, unfinished actions, current statuses, business context, and fixed-price settings. The operator can still review or override the scope before delivery.

Show the ready status and preview. Select **Next**.

## 2:25–2:50 — Send Kit

The existing Fast Lane session opens directly at Send Kit.

> Route-specific email, contact-form, text, proposal delivery, and follow-up copy are ready to edit or copy. Opening a PDF or copying text never marks outreach sent; that requires an explicit confirmation.

Show the route tabs and PDF actions.

## 2:50–3:00 — Close

> Snapshot Studio connects research, judgment, delivery, and follow-up in one local-first workflow—without automatic crawling, invented facts, or guaranteed results.

Select **Finish**. Mention that **Reset Starter Workspace** restores only the fictional demo chain to its pristine state.

## If the tour was previously dismissed

Select **Restart tour** beside the Starter Workspace controls. The dismissal is remembered only in the current browser.
