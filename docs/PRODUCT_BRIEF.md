# Snapshot Studio — Product Brief

Snapshot Studio is an internal outreach tool for creating fast, consistent AI Search / SEO visibility snapshots for local businesses.

## Primary goal

Help the user create a free 3-point AI Search Visibility Snapshot in 5 minutes or less, then generate outreach messages and a paid PDF report upsell.

## Target users

Internal use only at first.

## Target prospects

- Contractors
- ADU builders
- Remodelers
- Roofers
- Dentists
- Med spas
- Chiropractors
- Attorneys
- Local home service businesses

## Core workflow

1. Enter business info.
2. Score visibility categories.
3. Add quick notes from website review.
4. Generate:
   - Free 3-point snapshot
   - Contact form message
   - Text message
   - Follow-up message
   - Paid PDF report upsell
5. Save snapshot locally.
6. Copy outreach copy.

## Do not build yet

- No backend
- No login
- No paid subscriptions
- No automated scraping
- No Google API
- No OpenAI API
- No PDF generation API yet
